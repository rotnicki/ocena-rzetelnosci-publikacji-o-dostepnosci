# Materiały badawcze prowadzące do wersji 0.4

Ten katalog przechowuje roboczy protokół badania przenośności metodologii
pomiędzy rodzinami AI. Protokół przygotowano podczas prac nad wersją 0.3, ale
badanie nie zostało rozpoczęte i nie było warunkiem wydania 0.3.

Przedmiotem ewentualnego przyszłego badania będzie zamrożona i oficjalnie
wydana metodologia 0.3. Wyniki mogą uzasadnić zmiany w przyszłej wersji 0.4,
lecz sam protokół nie jest zatwierdzoną metodologią 0.4.

Plik `protokol-B2-przenosnosc-AI.md` jest bajtową kopią kompletnego protokołu
przygotowanego w projekcie 0.3. Jego SHA-256 wynosi:

`a914a919cd970bf744819cfd44982704eceaa10b27ea6fb37ae389b011ba8c65`

Sześć prywatnych przestrzeni roboczych z zamrożonym wejściem zachowano poza
publicznym repozytorium. Nie zawierają wyników ocen. Problemy organizacyjne lub
techniczne z dostępem poszczególnych AI nie są wynikiem naukowym ani wynikiem
metodologii.
