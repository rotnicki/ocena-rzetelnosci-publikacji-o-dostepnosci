# 0.1.0 — pierwsza zamrożona wersja eksperymentalna

## Status

To opublikowana wersja przedpremierowa. Jest historycznym, niezmiennym punktem odniesienia, a nie stabilnym wydaniem 1.0.

## Podstawa

- źródłowy commit kompletnej metodologii i umiejętności: `af83066983e832cd7f61b7c2bd99482a07731afc`;
